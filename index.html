고졸·마이스터고 채용 모아보기

공기업·대기업 공채 + 가점 자격증 한눈에

공고 데이터는 사람인 검색 결과를 자동 수집한 것으로, 원문과 다를 수 있습니다. 지원 전 반드시 각 공고 원문을 확인하세요.

가점 수치는 예시입니다. 같은 회사라도 공고마다 배점과 인정 자격이 다릅니다. 반드시 해당 채용공고의 '가산점/우대사항' 원문을 확인하고, 관련 계열 자격은 보통 최고 등급 1개만 인정됩니다.

내 자격증으로 기업 찾기

보유한 자격증을 추가하면 해당 자격증을 우대·가점으로 반영하는 기업을 추천해요.

자격증 목록에서 선택하거나 이름을 입력하세요.

추천 기업

추천 결과는 자격증 가점표 데이터에 등록된 정보 기준입니다. 실제 인정 자격증과 가점은 채용 공고 원문에서 확인하세요.

공기업·대기업 위치

빨간 점을 누르면 해당 기업과 본사 소재 지역을 볼 수 있어요.

기업 본사 소재 지역

지도 점은 본사 소재 시·군의 대표 위치를 나타냅니다.

표시 기업

표시 위치는 본사 소재 지역 기준의 참고용입니다. 세부 주소는 각 기업의 공식 홈페이지에서 확인하세요.

데이터 갱신 방법

이 사이트는 정적 페이지입니다. 공고 데이터를 새로 받으려면 터미널에서:

python scraper\run.py

명령을 실행하면 사람인에서 주요 공기업·대기업·고졸 관련 공고를 다시 수집해 data/jobs.js를 갱신합니다. 브라우저에서 새로고침하면 됩니다.

마이스터고 전형 참고

  • 삼성·현대차 등의 마이스터고 대학 진학 전형은 별도(졸업 예정자 대상). 취업 전형은 각 기업 채용 홈페이지 확인.
  • 공기업 고졸 공채는 상시 채용(기간제·대체인력)과 정기 공채(채용연계형)로 나뉩니다. 정기 공채는 인적성+면접 중심.
  • 가점 자격증은 동일 계열 중 최고 등급 1개만 인정되는 경우가 많아, 기능사→산업기사 상위 등급 취득이 유리합니다.

면책

본 사이트는 취업 정보를 편리하게 모아보기 위한 개인용 도구입니다. 채용 정보와 자격증 가점은 참고용이며 정확성을 보장하지 않습니다. 모든 전형 조건은 각 기업의 공고 원문이 기준입니다.
