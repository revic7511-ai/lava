# 고졸·마이스터고 채용 모아보기

고졸(마이스터고 포함) 기준 **공기업·대기업 채용공고**를 사람인에서 자동 수집해 한 화면에서 보여주고,
**공기업별 가점·우대 자격증(기능사/산업기사) 리스트**와 보유 자격증에 맞는 기업 추천 기능을 제공하는 정적 사이트입니다.

## 사용법

`index.html`을 브라우저로 열면 바로 사용할 수 있습니다 (서버 불필요).

공고 데이터를 최신으로 갱신하려면:

```
python scraper\run.py
```

- 사람인 검색에서 공기업·대기업·고졸 관련 공고를 수집합니다 (검색어별 최대 40건).
- `data/jobs.js`, `data/jobs.json` 이 갱신되고, `data/certs.js` 가 자격증 데이터에서 재생성됩니다.
- 브라우저에서 새로고침하면 반영됩니다.

## 구성

```
index.html            사이트 (채용공고 / 자격증 가점표 / 기업 추천 / 기업 지도 / 이용안내 탭)
assets/css/style.css  스타일
assets/js/app.js      화면 로직 (필터, 정렬, 자격증 기반 기업 추천 등)
data/jobs.js          수집된 채용공고 (자동 생성)
data/jobs.json        〃 (원본 JSON)
data/fields.js        직무 대분류 정의 (토목·기계·건설 등 키워드 매핑)
data/certs.json       공기업별 가점·우대 자격증표 (수동 편집)
data/certs.js         〃 (자동 생성)
data/company-locations.js 기업 지도용 본사 소재 지역 좌표
data/companies.json   공기업/대기업 분류 키워드
scraper/saramin.py    사람인 검색 수집·파싱 모듈
scraper/run.py        수집 실행 스크립트
```

## 커스터마이징

- **검색어 추가/삭제**: `scraper/run.py`의 `QUERIES` 목록 수정.
- **자격증 가점표 수정**: `data/certs.json`의 `companies` 항목 편집 → `python scraper\run.py` 재실행(또는 certs.js만 재생성).
- **가점 수치는 예시**입니다. 같은 회사도 공고마다 배점이 다르므로 반드시 각 채용공고의 가산점 항목을 확인하세요.
- **기업 추천** 탭에서 보유 자격증을 추가하면 해당 자격증을 우대·가점으로 등록한 공기업·대기업을 매칭 수 순으로 확인할 수 있습니다. 목록은 현재 브라우저에 저장됩니다.

## 회원가입 (Supabase 연동)

사이트에 회원가입/로그인 기능이 있고, 회원 정보(이름·학교명·기수·학년·과)는 Supabase에 저장됩니다.

### 최초 설정 (1회)

1. Supabase 대시보드 → **SQL Editor** → New query 에서 `supabase/schema.sql` 내용을 전부 붙여넣고 **Run**.
   - `profiles` 테이블(회원 정보)과 `posts` 테이블(커뮤니티 게시글) 생성,
     본인 데이터만 수정 가능한 RLS 정책, 가입 시 프로필 자동 생성 트리거가 만들어집니다.
   - **스키마를 추가/수정할 때마다 이 파일을 다시 실행하면 됩니다** (재실행 안전하게 작성됨).
2. 연결 정보는 `assets/js/supabase-config.js`에 이미 설정되어 있습니다. (프로젝트 URL / anon key / 공용 클라이언트 `window.sb`)

### 커뮤니티

- 글쓰기는 비회원도 가능하며, 글쓰기 시 학교명·기수·학년·과를 필수로 입력합니다.
- 로그인한 회원이 쓴 글은 본인이 삭제할 수 있습니다 (비회원 글은 삭제 불가).
- 댓글은 회원만 작성할 수 있으며, 본인 댓글만 삭제할 수 있습니다 (RLS로 강제).

### 이메일 인증 끄기 (선택)

기본값은 가입 후 이메일 인증이 필요합니다. 인증 없이 바로 가입되게 하려면:
대시보드 → **Authentication → Sign In / Providers → Email** 에서 **Confirm email** 을 끄면 됩니다.
